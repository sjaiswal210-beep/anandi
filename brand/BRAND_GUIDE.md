## Typography

- **Headlines / wordmark:** Inter / Segoe UI, weight 800–900.
- **Body:** Inter, 400–600.
- **Serif accent (monogram "RL"):** Georgia / Times New Roman.
- Devanagari (Marathi/Hindi collateral): Noto Sans Devanagari.

## Logo usage

- **On dark backgrounds:** use `logo-on-dark-*.png` (master as-is) or the SVG.
- **On light/print backgrounds:** use `logo-on-white-*.png`.
- **Overlay on photos / flex:** use `logo-transparent-*.png` (background keyed out).
- **App icon / avatar:** `mark-*.png` (square icon) or `avatar-*.png` (padded, circular-safe).
- Minimum clear space around the logo = height of the "RL" monogram.
- Do not stretch, recolor, add shadows, or place gold logo on gold.

## Generated files (in `brand/dist/`)

See the index printed by the build script. Categories:
- `logo-on-dark/` — square + wide, at 512 / 1024 / 2048 / 4096 px
- `logo-on-white/` — same, composited on white
- `logo-transparent/` — dark background keyed out (PNG with alpha)
- `mark/` — the emblem/icon crop, square, multiple sizes
- `favicon/` — 16, 32, 48, 180 (apple-touch), 512
- `social/` — profile avatars (IG/FB/YT), FB cover, IG post, IG story templates
- `print/` — 300 DPI versions for flex/banner/hoarding
- `web/` — optimized copies copied into apps/web/public for the site

## Print / flex notes

- Flex and hoarding files are 300 DPI. For a physical banner, tell the printer
  the finished size in feet; the vector SVG (`rich-land-logo.svg`) scales to any
  size without quality loss and is the best source for large-format print.
- For a true editable Photoshop file, open any `print/*.png` or the SVG in
  Photoshop/Illustrator. A layered `.psd` cannot be generated headlessly here —
  see BRANDING_NOTES section below for the recommended path.
